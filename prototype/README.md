# Dig Deeper — 프로토타입 (M0 / M2)

의존성 없는 단일 HTML 파일. `prototype/index.html`을 브라우저로 열면 바로 실행된다.
빌드 도구도 서버도 필요 없다.

```
xdg-open prototype/index.html      # 또는 그냥 파일을 브라우저에 드래그
```

## 조작

| 키 | 동작 |
|---|---|
| `A` / `D` | 이동. 벽에 닿은 채 누르면 좌우 굴착 (공중에서도 가능) |
| `S` | 아래 굴착. 드릴이 암반을 짚어 등속 하강한다 |
| `W` / `Space` | 발밑 부스터 — 등속 상승 |
| `Esc` | 일시 정지 — 남은 산소 / 귀환 필요 산소 확인, 하강 포기 |
| `F` | 코어 드릴 — 아래 5칸 관통 (드릴 정점 해금 시) |
| `Q` | 귀환 앵커 — 즉시 지상 귀환 (부스터 정점 해금 시) |

## 산소 (가장 중요한 규칙)

산소는 **오직 현재 깊이로만** 줄어든다.

```
소모율 = 0.60 + 깊이 × 0.0100     (무강화)
```

굴착, 부스터 분사, 적재 초과, 지층 환경 — 어느 것도 산소를 먹지 않는다.
각각의 대가는 시간·연료·이동속도·내구로 따로 받는다. 그래서 HUD의 두 숫자만
보면 판단이 끝난다.

- **`O₂/s`** — 지금 깊이의 소모율 (수식까지 그대로 표시)
- **`귀환 필요 ≈ N O₂`** — 지금 깊이에서 지상까지 오르는 데 드는 산소.
  남은 산소보다 커지면 빨갛게 바뀐다 → 그 전에 올라와야 한다.

## 귀환하는 법

위로는 **팔 수 없다**. 올라가는 수단은 부스터뿐이고, 연료는 충전해야 한다.

| 상태 | 충전 | 낙하 속도 |
|---|---|---|
| 접지 | 100% (34/s) | — |
| 좌우 벽에 닿아 버티기 | 80% (27/s) | 55 px/s |
| 활공 — 연료 0에서 W 유지 | 45% (15/s) | 100 px/s |
| W를 놓고 자유낙하 | 0 | 최대 700 px/s (낙하 피해) |

연료가 마르면 **35%까지 채워야 재점화**된다. 그래서 귀환은
「태우고 → 버티며 채우고 → 다시 태운다」의 반복이다.
1타일 수직 샤프트는 굴뚝이 되어 **활공보다 4배 빠르게** 오를 수 있다 —
내려갈 때 샤프트를 곧게 파 두는 것이 그대로 귀환 속도가 된다.

**W는 언제 눌러도 손해가 없다.** 연료가 없어도 활공하므로 자유낙하보다 항상 낫다.

머리 위가 막혔다면 위로는 팔 수 없으니 옆을 파야 한다 —
이때 게임이 **어느 쪽으로 몇 칸 파면 열리는지** 화살표로 알려준다.

## 진행

한 판이 끝나면 골드로 스킬 트리를 강화한다. **5갈래 35노드 + 교차 7노드** —
폐 / 드릴 / 등짐 / 부스터 / 탐사. 상위 티어는 **해당 갈래 누적 포인트**로 열린다
(T2 = 1PT, T3 = 5PT, T4 정점 = 7PT + 코어 조각 3, 교차 = 두 갈래에 각 6PT). 진행 상황은 `localStorage`에 저장된다
(`digdeeper.proto.v1`). 허브의 `기록 초기화`로 리셋.

## 밸런스 계측

콘솔에서 `window.DD`로 내부 상태를 읽을 수 있다.

```js
DD.run                 // 현재 판 상태 (깊이·산소·연료·적재·cling/gliding/relight)
DD.stats               // 스킬 반영 최종 스탯
DD.drainRate(300)      // 깊이 300m의 산소 소모율
DD.returnCost()        // 지금 깊이에서 지상까지 필요한 산소
DD.estimateLimit()     // 현재 빌드의 무보급 직하강 왕복 한계 깊이
DD.bandAt(300)         // 깊이 300m의 밴드 프로파일
DD.tileAt(16, 120)     // 타일 조회 (생성기 검증용)
```

## 자동 플레이테스트에서 잡은 버그

프로토타입은 Playwright로 자동 플레이해 검증했다. 기획서상으로는 보이지 않던 것들:

1. **귀환이 물리적으로 불가능했다.** 연료를 접지 중에만 충전하게 두니, 수직 굴착으로
   내려가면 착지할 곳이 없어 상승 8회 시도 순진척 +0m. → 굴뚝 버티기 도입.
2. **스킬 티어 게이트가 도달 불가능했다.** 갈래 최대 12PT인데 T2 게이트가 3(T1은 1랭크
   상한), T4 게이트가 14였다. → 0/1/5/9로 교정.
3. **아래로 파는 것만으로 내구가 갈렸다.** 낙하 중에도 다음 타일이 사정거리에 들어와
   무한 연쇄 추락 → 타일마다 낙하 피해 −18. → 드릴이 암반을 짚는 지지 상태로 처리.
4. **첫 판 수익이 27 G였다** (목표 ~120 G). 1타일 샤프트는 한 열만 샘플링한다.
   → 상단 밴드 광석 밀도 상향, 실측 124~283 G.
5. **만빌드가 완전 자급이 됐다.** 「회수 호흡」이 강해 산소가 줄지 않아 후반에
   "산소 = 제한 시간"이 무의미해졌다. → 계수 환원 + 광역 굴착 덤 타일은 산소 미지급.

### v0.3에서 추가로 잡은 것

6. **연료 0에서 W를 누르면 부스터가 프레임 단위로 점멸**했다. 분사 중에는 충전이
   멈추므로 플레이어가 스스로 충전을 방해해 순 상승이 0이었다(73m에서 30초간 제자리).
   → 재점화 임계치 35%.
7. **동굴에서는 벽이 없어 자유낙하로 진척이 전부 사라졌다.** 사이클 산술을 계산해
   보니 활공 이전 수치는 사이클당 **−341px**, 즉 영원히 오를 수 없었다.
   → 활공 도입 + 굴뚝 55 px/s · 활공 100 px/s · 공중 충전 45%로 두 경로 모두 양수화.
8. **타일 20px → 32px 전환에서 벽 감지 프로브가 플레이어 자기 타일에 갇혔다.**
   히트박스 여유가 4px인데 프로브 오프셋이 ±3px이었다. → 픽셀 오프셋 대신
   "점유 칸의 바로 옆 칸"으로 계산해 타일 크기와 무관하게 만들었다.
9. **랜턴 스킬이 암흑이 없는 지층에도 안개를 켰다** — 표토층 29m가 캄캄했다.
10. **`drawPlayer`에 카메라 오프셋이 빠져 플레이어가 화면에 보이지 않았다.**
